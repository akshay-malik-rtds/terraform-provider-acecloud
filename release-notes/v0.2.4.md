## Fixes for the v0.2.3 release pipeline and Registry sidebar

v0.2.4 fixes two cosmetic defects from v0.2.3. No provider behavior or schema changes; no state migration is required.

### Fixes

- **`acecloud_api_key` now appears under the IAM subcategory in the Registry sidebar.** In v0.2.3 the resource's description contained a paragraph break that corrupted the page's YAML frontmatter, so the Registry parsed an empty `subcategory` and bucketed the page under the catch-all "Resources" group. The description has been collapsed to a single paragraph.
- **GitHub Release body is now populated.** The v0.2.3 release shipped with an empty body because `changelog: disable: true` in `.goreleaser.yml` silently ignored the `--release-notes=…` flag (documented GoReleaser behavior). The config now uses an exclude filter instead of `disable`, so the per-version release notes file becomes the release body.

### Migrating from v0.2.3

No action required. Same provider source, version pin (`~> 0.2`), and schema arguments.
