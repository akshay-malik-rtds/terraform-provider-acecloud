## Documentation and packaging cleanup

v0.2.3 is a documentation and packaging release. No provider behavior or schema changes; no state migration is required.

### Registry presentation

- Provider page H1 is now **AceCloud Provider** (previously rendered as lowercase `acecloud Provider`). Sidebar entries are unchanged.
- The multi-region and multi-project content has been moved out of the provider overview into a dedicated **Guides → Multi-region and multi-project setups** page, so the overview reads top-to-bottom in under a screen.
- The `api_url` section has been tightened: it states only that the field is optional and shows the production default. Other doc surfaces (resource descriptions, `acecloud_api_key` resource, examples) were already cleaned in v0.2.2; v0.2.3 carries that polish through to the index page.

### Release notes

- This release is the first to ship with a populated GitHub Release body. From v0.2.3 onward, every release publishes a human-readable summary on the Releases page.

### Migrating from v0.2.2

No action required. The provider source attribute, version pin (`~> 0.2`), and all schema arguments are unchanged.
