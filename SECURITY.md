# Security Policy

## Supported Versions

Only the latest minor version of the AceCloud Terraform Provider receives security updates.

| Version | Supported |
|---------|-----------|
| Latest minor (e.g. 0.1.x) | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in the AceCloud Terraform Provider, **please do not open a public GitHub issue**.

Instead, report it privately to:

- **Email**: security@acecloud.ai
- **Subject**: `[Terraform Provider] <short description>`

Please include:

- Provider version affected
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations (if known)

## What to Expect

- **Acknowledgement**: Within 3 business days
- **Initial assessment**: Within 7 business days
- **Fix timeline**: Coordinated with you based on severity
- **Disclosure**: Coordinated public disclosure after a fix is released

## Scope

This policy covers:

- The provider source code in this repository
- Released binaries on the Terraform Registry

This policy does **not** cover:

- Vulnerabilities in the AceCloud platform itself (report those to AceCloud's security team via the standard support channels)
- Issues in third-party Go dependencies (please report upstream)

## Recognition

We're happy to acknowledge security researchers who responsibly disclose vulnerabilities to us, with your permission.
