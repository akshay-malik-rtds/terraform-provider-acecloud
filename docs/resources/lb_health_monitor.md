# acecloud_lb_health_monitor (Resource)

Manages an Ace Cloud Load Balancer Health Monitor.

## Example Usage

```terraform
resource "acecloud_lb_health_monitor" "http" {
  name           = "http-healthcheck"
  pool_id        = acecloud_lb_pool.http.id
  type           = "HTTP"
  delay          = 10
  timeout        = 5
  max_retries    = 3
  url_path       = "/health"
  expected_codes = "200"
  http_method    = "GET"
}
```

## Schema

### Required

- `delay` (Number) Delay between health checks in seconds.
- `max_retries` (Number) Number of successful checks before marking as healthy.
- `name` (String) Name of the health monitor.
- `pool_id` (String) ID of the pool to monitor.
- `timeout` (Number) Timeout for each health check in seconds.
- `type` (String) Health monitor type (HTTP, HTTPS, TCP, PING, TLS-HELLO, UDP-CONNECT, SCTP).

### Optional

- `expected_codes` (String) Expected HTTP response codes for HTTP/HTTPS checks (e.g. 200, 200-299). Defaults to 200.
- `http_method` (String) HTTP method for HTTP/HTTPS checks (GET, POST, etc.). Defaults to GET.
- `max_retries_down` (Number) Number of failed checks before marking as unhealthy.
- `url_path` (String) URL path for HTTP/HTTPS health checks (e.g. /health). Defaults to / for HTTP/HTTPS monitors.

### Read-Only

- `admin_state_up` (Boolean) Administrative state of the health monitor.
- `created_at` (String) Timestamp when the health monitor was created.
- `id` (String) Unique identifier of the health monitor.
- `operating_status` (String) Operating status (e.g. ONLINE, OFFLINE).
- `provisioning_status` (String) Provisioning status (e.g. ACTIVE, PENDING_CREATE).
