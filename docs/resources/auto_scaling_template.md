# acecloud_auto_scaling_template (Resource)

Manages an Ace Cloud Auto Scaling template. Templates define the instance configuration used when scaling out.

## Example Usage

```terraform
resource "acecloud_auto_scaling_template" "web" {
  name                   = "web-tier-template"
  type                   = "linux"
  description            = "Launch template for web tier auto scaling"
  volume_size            = 40
  vol_del_on_termination = true
  flavor_id              = var.flavor_id
  image_id               = var.image_id
  is_instance_snapshot   = false
  key_name               = acecloud_key_pair.generated.name
  network_id             = acecloud_vpc.main.id
  subnet_id              = acecloud_vpc.main.subnet_id
  security_groups        = [acecloud_security_group.web.id]
}
```

## Schema

### Required

- `flavor_id` (String) ID of the compute flavor to use.
- `is_instance_snapshot` (Boolean) Whether to boot from an instance snapshot (true) or an image (false).
- `name` (String) Name of the template. Must be 1-255 characters, alphanumeric with spaces, underscores, and hyphens.
- `network_id` (String) ID of the VPC network for scaled instances.
- `security_groups` (List of String) List of security group IDs to apply to scaled instances.
- `subnet_id` (String) ID of the subnet for scaled instances.
- `type` (String) Operating system type. Must be 'linux' or 'windows'.
- `vol_del_on_termination` (Boolean) Whether the volume is deleted when the instance is terminated.
- `volume_size` (Number) Volume size in GB for each scaled instance.
- `volume_type` (String) Volume type for the root volume of scaled instances. Accepts short aliases: `ssd` (or `nvme`) → `NVMe based High IOPS Storage`, `hdd` → `HDD based Storage`. The full name may also be used directly.

### Optional

- `description` (String) Description of the template (3-255 characters).
- `image_id` (String) ID of the image to boot from. Required when is_instance_snapshot is false.
- `key_name` (String) Name of the SSH key pair to inject.
- `snapshot_id` (String) ID of the instance snapshot to boot from. Required when is_instance_snapshot is true and source_instance_id is not set.
- `source_instance_id` (String) UUID of an existing instance to use as the template source. Alternative to snapshot_id when is_instance_snapshot is true.
- `user_data` (String) Base64-encoded cloud-init user data script to run on each scaled instance.

### Read-Only

- `created_at` (String) Timestamp when the template was created.
- `id` (String) Unique identifier of the auto scaling template.
- `region` (String) Region where the template was created.
- `status` (String) Current status of the template.
- `updated_at` (String) Timestamp when the template was last updated.
