# acecloud_subnet (Resource)

Manages an Ace Cloud subnet within a VPC.

## Example Usage

```terraform
resource "acecloud_subnet" "secondary" {
  name       = "secondary-subnet"
  cidr       = "10.0.1.0/24"
  vpc_id     = acecloud_vpc.main.id
  ip_version = 4

  enable_dhcp     = true
  gateway_ip      = "10.0.1.1"
  dns_nameservers = ["8.8.8.8", "1.1.1.1"]

  allocation_pools {
    start = "10.0.1.10"
    end   = "10.0.1.250"
  }
}
```

### Required

- `cidr` (String) CIDR block for the subnet (e.g. 10.0.1.0/24). Must be a valid IPv4 CIDR. Changing this forces recreation.
- `ip_version` (Number) IP version for the subnet. Must be 4 or 6. Changing this forces recreation.

- `dns_nameservers` (List of String) List of DNS nameserver IP addresses.
- `enable_dhcp` (Boolean) Whether DHCP is enabled on the subnet.
- `gateway_ip` (String) Gateway IP address for the subnet. Auto-assigned if omitted.
- `host_routes` (Block List) Host routes for the subnet. (see [below for nested schema](#nestedblock--host_routes))
- `vpc_id` (String) ID of the VPC (network) this subnet belongs to. Changing this forces recreation.
