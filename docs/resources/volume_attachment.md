# acecloud_volume_attachment (Resource)

Attaches an existing volume to an existing instance. Use this when you need to attach a volume to an instance that was created separately (e.g. attaching a data volume to a long-running instance after-the-fact). For volumes attached at instance creation time, use the `volumes` block on `acecloud_instance` instead.

## Example Usage

```terraform
terraform {
  required_providers {
    acecloud = {
      source  = "akshay-malik-rtds/acecloud"
      version = "~> 0.1"
    }
  }
}

provider "acecloud" {
  # Auth via environment variables:
  #   ACECLOUD_API_KEY_ID, ACECLOUD_API_KEY_SECRET, ACECLOUD_API_KEY_SERVICE_NAME
  #   ACECLOUD_REGION, ACECLOUD_PROJECT_ID
}

# An existing instance and volume managed by Terraform (or imported).
resource "acecloud_instance" "web" {
  name                  = "web-01"
  flavor_id             = "REPLACE_WITH_FLAVOR_UUID"
  boot_uuid             = "REPLACE_WITH_IMAGE_UUID"
  source_type           = "image"
  delete_on_termination = true
  network_ids           = ["REPLACE_WITH_VPC_UUID"]
  security_group_ids    = ["REPLACE_WITH_SG_UUID"]
  billing_type          = "hourly"

  volumes {
    size         = 20
    boot         = true
    volume_type  = "ssd"
    billing_type = "hourly"
  }
}

resource "acecloud_volume" "data" {
  name         = "shared-data"
  size         = 200
  volume_type  = "ssd"
  billing_type = "hourly"
}

# Attach the data volume to the instance.
# Use this resource (instead of an inline volumes block on the instance)
# when the volume and instance have independent lifecycles, or when
# attaching a pre-existing volume.
resource "acecloud_volume_attachment" "data" {
  instance_id           = acecloud_instance.web.id
  volume_id             = acecloud_volume.data.id
  delete_on_termination = false
}
```

## Schema

### Required

- `instance_id` (String) UUID of the instance to attach the volume to. Changing this forces re-attachment.
- `volume_id` (String) UUID of the volume to attach. Changing this forces re-attachment.

### Optional

- `delete_on_termination` (Boolean) Whether the volume should be deleted automatically when the instance terminates. Defaults to `false`. Changing this forces re-attachment.

### Read-Only

- `device` (String) Device path on the guest (e.g. `/dev/vdb`) once the attachment completes.
- `id` (String) Composite identifier `<instance_id>:<volume_id>`.
